# Unity Assets 골격

이 폴더는 실제 Unity 프로젝트에서 `Assets/`로 붙여넣기 좋은 최소 골격입니다. 게임 코드와 리소스를 정리할 때 아래 하위 폴더를 사용하세요.

```
Assets/
├── Scripts/
│   ├── Core/
│   ├── Systems/
│   ├── Gameplay/
│   └── Shared/
├── Art/
├── Audio/
├── Resources/
└── Scenes/
```

> 저장소에는 리소스가 포함되어 있지 않으므로, 필요한 아트/오디오/프리팹을 추가로 넣어 사용하면 됩니다. 폴더 설명과 Java→Unity 매핑은 `../docs/folder-map-ko.md`를 참고하세요.
